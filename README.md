本地优先的 Obsidian 插件：用**可版本化能力蓝图（Blueprint）**定义每本记录本的能力；同一插件可运行多个互不干扰的 AI 记录本。条目以 Markdown 落盘，**功能版本回滚不会改写用户笔记内容**。

## 只要这一小份就能用

**结论：只需要 `release/ai-notebook/` 里的文件，不必下载/解压整个仓库。**

仓库里还有 `src/`、`docs/`、`tests/` 等，那是**开发与构建**用的。插件运行时已经打进 `main.js`，**不依赖** GitHub 仓库、不依赖源码目录，也和别人的密钥/笔记无关。

### 最终只要这 3 个文件

```text
.obsidian/plugins/ai-notebook/
  ├── manifest.json   # 插件身份与版本
  ├── main.js         # 全部逻辑（已打包）
  └── styles.css      # 样式
```

| 你拷什么 | 能否正常运行 |
|----------|----------------|
| **仅** `release/ai-notebook/`（上面 3 个文件） | ✅ 可以 |
| 整个仓库（源码 + 文档 + 测试） | 能 clone，但**装插件时用不到**，纯多余 |
| Tag 的 Source code 整夹当插件目录 | ❌ 不行（见下） |

### 最短安装步骤

1. 取得安装文件（任选其一）：
   - **推荐**：Releases 里的 `ai-notebook-vX.Y.Z.zip`（解压即是这 3 个文件）  
   - 或：仓库 / 本机路径里的 [`release/ai-notebook/`](release/ai-notebook/)  
   - 或：Tag 的 Source code zip → **只进入**其中的 `release/ai-notebook/`  
2. 复制到：`<你的库>/.obsidian/plugins/ai-notebook/`  
3. 设置 → 社区插件 → 关闭受限模式 → 启用 **AI 记录本**  
4. （可选）在插件设置里自己填 Base URL、API Key、模型  

**更新**：只覆盖这 3 个文件；**不要删** 同目录下的 `data.json`（你自己的 Key 与设置）。

### 和「整仓下载」的关系

- **没有**「必须整仓才能跑」的关联。  
- 别人部署 = 拷运行包 + **自己**配 API；不会读到你本机的密钥或笔记。  
- 只有要改代码、跑测试时，才需要完整 clone 并 `npm install` / `npm run build`。

## 0.2.0 亮点

相对 `0.1.x`，本版重点强化**可交互助手**与**可恢复的对话附件**：

| 能力 | 说明 |
|------|------|
| **浮层 AI 对话** | 可拖拽、缩放、收放；默认仅右下角「助手」按钮，避免挡内容 |
| **助手真写入** | 改正文/字段、新建条目；图片/视频可 `embed_in_body` 写入正文并可预览播放 |
| **本轮附件隔离** | 本轮命令只针对本轮上传，不再把历史上传误混进「本轮附件」 |
| **拖拽 / 粘贴上传** | 输入区支持拖入文件、Ctrl+V 粘贴截图 |

| **多模型有序回退** | 规划 / 助手 / 语音各可配顺序 1→2→3；看图能力失败自动切换 |
| **记录本 / 条目选择** | 浮窗内切换上下文，与主界面双向同步 |

## 功能总览

### 记录本与数据

- **多实例记录本**：独立目录、蓝图版本、条目列表、收藏柜  
- **模板**：文献 / 灵感 / 会议 / 收藏向 / 空白  
- **Markdown 存储**：`items/*.md`，可被 Obsidian 搜索、同步、备份  
- **列表 / 表格 / 看板**：由蓝图 `views` 驱动，可筛选排序  

### 蓝图与版本

- 能力由 `blueprints/vNNNN.json` 描述  
- 手动提交版本、历史恢复、Diff 确认  
- 回滚蓝图**不改写**已有条目正文（未映射字段保留）  

### AI 能力

| 模式 | 对象 | 典型用途 |
|------|------|----------|
| **助手** | 当前（或选中的）**条目** | 改正文、插图/视频、描述画面、整理内容 |
| **改功能** | **整本记录本的蓝图** | 加字段、改视图、开收藏柜等「小插件」级能力 |
| **整理** | 条目 / 收件箱 | 杂乱文本 → 字段 + 分层正文 |
| **语音** | 录音 | Whisper / 兼容 transcriptions，或聊天多模态听音频 |

### 跨端

- 收件箱 `AI Inbox/pending` → AI 整理进本  
- 局域网手机网页入口  
- Cloudflare / ngrok 等公网隧道（可选）

## 安装与更新

> 核心就一句：**只装 `release/ai-notebook` 三文件即可**，见上文 [只要这一小份就能用](#只要这一小份就能用)。

### 方式 A：Release 安装包（推荐）

1. [Releases](https://github.com/ZNaiGaomu/AI-notebook/releases) → 下载 **`ai-notebook-vX.Y.Z.zip`**（附件，不是 Source code）  
2. 解压得到 `manifest.json`、`main.js`、`styles.css`  
3. 放入 `<库>/.obsidian/plugins/ai-notebook/`  
4. 启用插件 →（可选）配置自己的 API  

### 方式 B：只用仓库里的 `release/ai-notebook`

仓库体积大时，**不必**整仓克隆。只要拿到：

```text
release/ai-notebook/manifest.json
release/ai-notebook/main.js
release/ai-notebook/styles.css
```

复制到 `.obsidian/plugins/ai-notebook/` 即可运行。与整仓其它文件**无运行时依赖**。

### 方式 C：从 Tag 的 Source code zip

[Tags](https://github.com/ZNaiGaomu/AI-notebook/tags) 上的 **zip / tar.gz** = **整个源码树**，不能当插件根目录。

解压后进入 **`release/ai-notebook/`**，再只拷上述 3 个文件去 plugins。

### 对照表

| 下载物 | 能否直接当插件 |
|--------|----------------|
| Release 的 `ai-notebook-v*.zip` | ✅ 解压即装 |
| 仅 `release/ai-notebook/` 三文件 | ✅ 可直接装 |
| Tag / Code 的 Source code zip 根目录 | ❌ 须进入 `release/ai-notebook/` |
| 含 `src/`、`package.json` 的源码根 | ❌ 须先 `npm run build` |

### 更新

- 只覆盖 `manifest.json`、`main.js`、`styles.css`  
- **保留** `data.json`（本机 Key 与设置）  
- 建议禁用再启用插件，或重启 Obsidian  

### 从源码构建（仅开发需要）

```bash
git clone https://github.com/ZNaiGaomu/AI-notebook.git
cd AI-notebook
npm install && npm test && npm run package
# 产物：release/ai-notebook/
```

```bash
npm run build   # 生产构建并同步 release/ai-notebook
npm run dev     # 开发 watch
```

## 快速上手

1. Ribbon 点击 **AI 记录本**，或命令「打开 AI 记录本」  
2. **新建记录本** → 选模板  
3. **快速捕获** 或左侧列表维护条目  
4. 右下角 **助手** → 上传图/视频 →「插入正文并描述」  
5. 需要改结构能力时切到 **改功能**，确认 Diff 后应用

## 浮层助手（写笔记）

### 窗口

- 默认 **收起** 为右下角按钮  
- 可拖标题栏、右下角缩放；**尺寸/位置会记住**  
- 内含：助手 / 改功能、历史、新对话、记录本与条目选择  

### 写入规则（摘要）

- **默认**上传仅供参考，不自动进笔记  
- 明确说「插入正文 / 放进笔记」→ `embed_in_body`（正文 `![[path]]`，可预览/播视频）  
- 明确说「收藏柜」→ 才进收藏柜  
- **本轮附件**只含本轮上传；成功嵌入后从内存会话缓存移除（盘上历史文件仍在）  

### 历史（按条目）

- 助手历史绑定 **当前条目**  
- 进入条目默认 **接续最近会话**  
- **新对话**会真正新建线程（不会写回旧会话）  
- 每条会话：**打开** 进入对话；**附件…** 多选打开/下载该会话全部上传  

### 追加发送

- **排队**：上一条结束后自动发下一条  
- **引导**：补充到当前进行中的请求

## 改功能（改蓝图）

- 对象是整本记录本的 **功能配置**，不是某一条笔记正文  
- AI 生成完整蓝图 JSON → 校验 → **Diff 确认** → 提交新版本  
- 历史按 **记录本** 保存，不必按条目拆分

## AI 与多模型路由

设置 → **AI 服务商与模型** → **用途 → 服务商（有序回退）**：

| 用途 | 典型用途 |
|------|----------|
| 改功能 / 规划 | 蓝图编译 |
| 整理 / 助手 | 条目助手、看图、整理 |
| 语音转写 | Whisper 等 STT |

每个用途可配 **顺序 1 / 2 / 3**（不同服务商 + 模型）。前一个失败或不支持所需能力（如视觉）时自动尝试下一个。

支持 OpenAI 兼容 Base URL + API Key；可从上游拉取模型列表、测试连通。

## 附件、历史与路径设置

| 设置项 | 说明 |
|--------|------|
| 记录本根目录 | 默认 `AI Notebooks` |
| 附件根目录 | 条目嵌入等，默认 `attachments/ai-notebook` |
| **对话上传保存位置** | 默认 `{附件根}/chat-uploads`；可用 **选择文件夹…** 选电脑任意盘符路径 |
| **对话附件保留** | 默认永久；可关永久后填天数（清理策略可扩展） |
| 手机收件箱 | 默认 `AI Inbox` |

对话附件：一点上传/粘贴/拖入即写入配置目录，供历史二次打开下载；与「是否写入笔记正文」无关。

## 手机与收件箱

详见插件设置中的「手机网页入口」与命令面板相关项。

## 隐私与数据边界

### 开源仓库里有什么 / 没有什么

| 内容 | 是否在 GitHub 仓库中 |
|------|----------------------|
| 源码、`main.js` 安装包 | ✅ 有（供他人自行部署） |
| 你的 API Key | ❌ 无（只在本机 `data.json`，已 gitignore） |
| 你的笔记 / 对话 / 上传文件 | ❌ 无（只在你自己的 Obsidian 库） |

别人下载 `release/ai-notebook` 或 Source code，得到的是**空配置软件**，须自己填写自己的 Key。

### 数据何时会离开本机

仅当你在本机配置了 AI 并调用时，请求发往**你填写的**服务商，可能含对话、条目摘要、图片等。这是「你 → 你的 API」，不是「你 → 其他 GitHub 用户」。

### 使用者注意

- 自行准备 OpenAI 兼容 Base URL 与 API Key  
- 不要把含真实 Key 的 `data.json` 提交到公开仓库  
- 助手写入会修改 Markdown，请备份库
