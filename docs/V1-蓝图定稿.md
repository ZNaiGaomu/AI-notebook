# AI 记录本（Obsidian 插件）V1 蓝图定稿

> 状态：**P0–P4 MVP 已实现并通过自动化测试**（2026-07-19）  
> 选项已全部按推荐冻结  
> 形态：Obsidian Community Plugin  
> 原则：固定解释器 + 可版本化能力蓝图；AI 只产出蓝图与操作计划；数据与功能版本隔离

---

## 0. 身份与范围

| 项 | 定值 |
|----|------|
| 显示名 | AI 记录本 |
| plugin id | `ai-notebook` |
| 后端 | 无；纯本地插件 + 用户自备 API |
| 手机 | 同一插件；手机只作 vault 内容入口，不自建独立存储 |
| 第一期代码目标 | **P0 + P1**（P2 语言改功能为紧随其后的下一刀） |

### 0.1 架构一句话

> 数据是用户资产，功能是可版本化配置；AI 是配置编译器，不是代码注入器；Obsidian 是壳与同步媒介，插件是安全的声明式运行时。

### 0.2 明确不做（V1）

- AI 生成/热替换插件 JS 源码  
- 自建云同步 / 中转 API Key  
- 可视化工作流编排器  
- 看板 Board / 复杂表格（P0–P1 仅 List + 详情 + 对话壳）  
- BT/全网下载、默认整站抓取  
- 任意代码执行类 workflow step

## 2. 仓库与目录约定（Vault）

可在设置中修改「记录本根目录」与「附件根」，以下为默认：

```
vault/
  AI Notebooks/
    {displayName}/
      _notebook.md                 # type: ai-notebook；见 §2.1
      blueprints/
        index.json                 # 版本列表摘要
        v0001.json
        v0002.json
        ...
      items/
        2026-07-19-a1b2c3.md
      cabinet/
        links.json                 # 链接条目数组或分片索引
        files.json                 # 文件元数据（真实文件在 attachments）
      .trash/
        items/...
        cabinet/...

  attachments/
    ai-notebook/
      {notebook_id}/
        ...                        # 复制入库的文件

  .obsidian/
    plugins/
      ai-notebook/
        main.js
        manifest.json
        data.json                  # loadData/saveData：密钥、Providers、UI 状态
```

```yaml
---
ai_notebook: true
notebook_id: "uuid-..."
```

## 4. Blueprint 文件结构（V1 Schema 骨架）

每个 `vNNNN.json` 顶层：

```json
{
  "$schema": "ai-notebook-blueprint/v1",
  "blueprintVersion": 1,
  "name": "文献本",
  "description": "模板：文献搜集",
  "entityTypes": [],
  "views": [],
  "commands": [],
  "hooks": {
    "onCreate": []
  },
  "cabinet": {
    "enabled": true,
    "buckets": ["links", "files"]
  },
  "aiBehaviors": {
    "systemHints": "",
    "allowedTools": ["searchItems", "createItem", "updateItem"]
  },
  "ui": {
    "primaryView": "list",
    "homePrompt": "描述你想记录的内容…",
    "featureEditPrompt": "描述你想如何改这个记录本的功能…"
  }
}
```

### 4.1 entityType

```json
{
  "id": "literature",
  "label": "文献",
  "fields": [
    {
      "id": "title",
      "label": "标题",
      "type": "text",
      "required": true,
      "showInList": true
    }
  ],
  "list": {
    "sort": "updated_desc",
    "filterFields": ["status", "tags"]
  }
}
```

### 4.2 字段类型白名单（Q7=A）

| type | 说明 |
|------|------|
| `text` | 单行 |
| `markdown` | 多行 MD |
| `number` | 数字 |
| `date` | 日期 |
| `url` | URL |
| `select` | 单选，`options: string[]` |
| `multi-select` | 多选 |
| `tags` | 标签 |
| `checkbox` | 布尔 |
| `note-ref` | vault 笔记路径/链接 |
| `file-ref` | 附件相对路径 |

未知 `type` → **校验失败，拒绝应用蓝图**。

### 4.3 views（list / table / board）

```json
{ "id": "main", "type": "list", "entityType": "literature" }
```

`type` 允许：`list` | `detail`（detail 为内置侧栏）| `table` | `board`。  
UI 按蓝图 `views` 声明提供切换；默认取 `views` 中第一个 list|table|board。  
`board` 列字段：实体中首个 `select`（优先 `list.filterFields`）。

### 4.4 commands（action 白名单）

| action | 含义 |
|--------|------|
| `openCaptureModal` | 快速捕获 |
| `openChat` | 打开助手 |
| `openFeatureEdit` | 打开改功能模式（P2） |
| `refreshList` | 刷新 |

```json
{
  "id": "quick-capture",
  "label": "快速捕获",
  "action": "openCaptureModal",
  "entityType": "literature"
}
```

### 4.5 hooks.onCreate（step 白名单）

| type | 含义 | 阶段 |
|------|------|------|
| `ai.extract` | 按当前 entity 字段抽取（已实现；已 structured 则跳过） | 已实现 |
| `cabinet.attachIfUrl` | 若有 url 字段写入 links，并回写 cabinet_refs | 已实现 |
| `notify` | Notice 提示 | 已实现 |

禁止：`eval`、任意 shell、任意网络（除 AIGateway）、任意 vault 外路径。

### 4.6 aiBehaviors.allowedTools（对话工具白名单，P2+）

`searchItems` | `createItem` | `updateItem` | `addCabinetLink` | `proposeBlueprint`（仅改功能模式）

## 5. 版本、Diff 与恢复

### 5.1 Commit

```
validate(blueprint) → 失败则拒绝
version = max+1
write blueprints/v{version}.json
append index.versions
index.current = version
_notebook.md current_blueprint = version
CapabilityRuntime.hotReload()
```

### 5.2 Restore(k)

```
load v{k}.json（只读历史文件，不删历史）
以「restoredFrom: k」为 changeSummary 再走一遍 Commit（新 version）
→ 历史仍可追溯；回滚可再回滚
```

### 5.3 Diff 展示（确认弹窗）

本地计算：

- 新增/删除/修改的 entityTypes、fields、commands、hooks  
- 人话摘要（P2 可由 AI 附带 `changeSummary`，P1 手改 JSON 时本地生成）  
- **每次确认**后才 Commit  

### 5.4 数据隔离

- Restore **绝不**批量改写 `items/*.md` 正文  
- 读条目时：`SchemaMigrator.project(item, currentBlueprint)`  
  - 蓝图内字段 → 正常表单  
  - 其余 frontmatter 业务键 → 「扩展/未映射」只读折叠（可高级编辑）  
  - 不删除未知键

## 6. 模板库（Q3=B）

创建记录本时可选：

| template_id | 说明 |
|-------------|------|
| `blank` | 单实体 `note`：title + body(markdown) + tags；无柜或柜关 |
| `literature` | 文献：title, url, authors(text), status(select), notes；柜开 |
| `idea` | 灵感：title, body, tags, mood(select) |
| `meeting` | 会议：title, date, attendees, decisions, notes |
| `cabinet-first` | 偏收藏：轻量 item + 柜默认开 |

模板 = 预置 `v0001.json` 内容；创建后用户可（P2）语言改功能。

## 7. AI Provider 与网关

### 7.1 Profile

- 增 / 删 / 切换默认  
- 字段：`id, name, baseUrl, apiKey, models[], defaultModel`  
- `baseUrl` 规范化：用户可填到 `/v1` 或源站，网关统一拼路径  

### 7.2 用途路由

| purpose | 用途 |
|---------|------|
| `planner` | 改功能、产蓝图 |
| `worker` | 抽取字段、摘要、助手 |
| `voice` | 转写 |

解析顺序：记录本 `model_overrides` → 全局 `purposeRouting` → `defaultProviderId`+`defaultModel`。

### 7.3 端点

- `POST {base}/chat/completions`  
- `POST {base}/audio/transcriptions`（P4；不支持则 UI 隐藏语音）  

### 7.4 上下文策略（Q15）

| 场景 | 默认附带 |
|------|----------|
| 改功能 | 当前蓝图 JSON + 用户指令 +（可选）字段使用统计 |
| 助手/抽取 | 字段定义 + 当前条目或用户选中 + 指令 |
| top-k | 仅当 `privacy.attachTopKItems=true` |
| 当前笔记全文 | 仅当显式开关且默认 false |

## 10. 手机与语音

- 同一插件；能力探测，桌面增强不阻塞移动

1. AIGateway 流式 chat

3. 用途路由 planner/worker

### P3 — 收藏柜

1. links/files CRUD
