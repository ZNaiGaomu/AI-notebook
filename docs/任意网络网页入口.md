# 任意网络都能打开的手机网页

## 你要的形态

> 电脑 Obsidian 给出一个链接 → 手机（4G/5G/别的 Wi‑Fi）点开就是网页 → 写字/录音 → 写回电脑笔记 → AI 整理

**可以做到。** 原理不是手机直接连你内网 IP，而是：

```
手机（任意网络）
    │  https://xxxx.trycloudflare.com/?t=令牌
    ▼
Cloudflare / ngrok 等公网隧道
    │
    ▼
电脑本机 http://127.0.0.1:27124  （Obsidian 插件小服务）
    │
    ▼
Vault 笔记 + AI 整理
```

电脑必须：**开着、Obsidian 开着、入口开着**。

## 用法（推荐）

### 方式 A：一键 Cloudflare 临时隧道

1. 安装 [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-apps/install-and-setup/installation/)  
   - Windows：安装后命令行能运行 `cloudflared`，或把 `cloudflared.exe` 路径填进插件设置  
2. 电脑插件命令：  
   - **`生成任意网络可打开的手机链接`**  
   - 或 **`显示手机网页入口链接`** → **生成任意网络链接（Cloudflare）**  
3. 复制 `https://….trycloudflare.com/?t=…` 到手机浏览器（流量也行）  
4. 写字 / 录音即可  

临时隧道每次生成地址可能不同；电脑关掉隧道就失效。

### 方式 B：ngrok（手动）

1. 安装 [ngrok](https://ngrok.com/)，登录拿 token  
2. 先启动插件本地入口（显示链接窗口里「仅启动本地服务」）  
3. 终端：

```bat
ngrok http 27124
```

4. 把 ngrok 显示的 `https://xxxx.ngrok-free.app` 填进插件设置 **公网地址（手动）**，或链接窗口里「保存并使用」  
5. 手机打开：`https://xxxx.ngrok-free.app/?t=你的令牌`  
   （令牌在链接窗口里，与局域网链接 `?t=` 相同）

## 安全

- 链接带 **token**，不要发到公开群  
- 这是「你电脑的写入入口」，泄漏等于别人能往你笔记灌内容  
- 不用时命令：**停止手机网页入口**  
- 不要用路由器端口映射裸奔公网 IP  

## 和「同一 Wi‑Fi」对比

| | 局域网链接 | 公网网页链接 |
|--|-----------|--------------|
| 网络 | 同一 Wi‑Fi | 任意网络 |
| 地址 | `http://192.168.x.x:27124/?t=…` | `https://xxx.trycloudflare.com/?t=…` |
| 额外软件 | 无 | cloudflared 或 ngrok |
| 电脑在线 | 需要 | 需要 |

两种链接在同一窗口都会列出；**出门用公网，在家可用局域网。**
