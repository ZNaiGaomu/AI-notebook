# AI 记录本 v0.3.1

小更新：插件整体历史的拉取优先级与「当前使用」标记更清晰。

## 安装

1. 下载 **`ai-notebook-v0.3.1.zip`**
2. 解压得到 `manifest.json` / `main.js` / `styles.css`
3. 复制到：`<库>/.obsidian/plugins/ai-notebook/`（更新时保留 `data.json`）

## 相对 0.3.0 的变化

- **拉取顺序**：Release 安装包附件 → 否则 Tags 源码 zip → 再否则 Code Download ZIP（不混通道）
- 每条版本标注拉取方式（Release 附件 / Tags 源码包 / Code Download ZIP）
- **「当前使用」** 只在你真正「下载并使用 / 切换本地备份」成功后标记；不再因版本号相同误标远程包
- 本地备份与每个 GitHub 来源仍是独立列表
