# 手机跨端 + AI 自动整理

## 架构链路

```
手机 Obsidian ──写入──► Vault「AI Inbox/pending」
        │                      │
        │     Obsidian Sync / iCloud / Syncthing / Git
        ▼                      ▼
电脑/手机插件 ◄──────── 同一知识库 ────────► AI 大模型（你自备 URL+Key）
        │                      │
        │  命令：处理收件箱      │  结构化 JSON
        ▼                      ▼
  记录本 items/（分层笔记）   原文 → processed/
```

**原则**：手机不自建存储，只是 vault 输入端；密钥在每台设备插件设置里本地配置。

## 手机怎么投递

1. 手机与电脑打开**同一个库**并开启同步。
2. 在手机新建笔记，放到文件夹：`AI Inbox/pending/`  
   （首次打开插件会自动创建，也可命令「初始化手机收件箱文件夹」）
3. 内容可杂乱：链接、待办、语音转文字、聊天摘录…
4. 同步后任意端执行：
   - 命令面板：`处理收件箱（AI 整理）`
   - 或记录本 → **收件箱** 页签 → 全部 AI 整理
5. 结果进入**当前/默认记录本**的 `items/`，按蓝图字段结构化。

也可在手机装同一插件，用命令：`手机速记（写入收件箱）`。

## 语音

1. 打开记录本 → **语音录入**（可开始/停止，不再固定 4 秒）
2. 转写 API（OpenAI-compatible `/audio/transcriptions`）
3. 若开启「语音后自动 AI 结构化」→ 抽字段 + 分层正文
4. 原文备份在 `AI Inbox/voice-raw/`

## AI 整理单条

选中条目 → **AI整理条目** 或命令 `AI 整理当前条目`。

## 设置项

- 手机收件箱目录（默认 `AI Inbox`）
- 整理后归档原文
- 语音后自动 AI 结构化
- Provider：worker（整理）、voice（转写）、planner（改功能）
