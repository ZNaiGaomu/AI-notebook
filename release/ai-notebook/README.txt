AI 记录本 (ai-notebook) — 安装包 v0.2.0

【结论】只需本文件夹内的 manifest.json / main.js / styles.css。
无需下载整个 GitHub 仓库；与 src、docs、tests 无运行时依赖。

【安装】
复制本目录三个文件到：
  <你的库>/.obsidian/plugins/ai-notebook/

然后：设置 → 社区插件 → 启用「AI 记录本」。
（可选）在插件设置中配置你自己的 API。

【从 Tag Source code 下载时】
解压后进入 release/ai-notebook/ 再复制上述文件，不要把源码根目录当插件。

【更新】
只覆盖三文件；不要删除 data.json（本机密钥与设置）。

【隐私】
本安装包不含任何 API Key 或笔记。密钥仅保存在你本机启用后的 data.json。
每人自行配置、自行使用。

更多说明见仓库 README：
